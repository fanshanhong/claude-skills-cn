## 正文

```
最近沉迷 Claude Code Skills 生态，发现一个痛点：

英文社区的 Skill 仓库（Obra/superpowers、Yeachan-Heo/oh-my-claudecode、affaan-m/ecc、garryslist/gstack 等）质量很高，但全是英文 SKILL.md，国内很多同学想用要先翻译一遍再消化。

干脆做了个站点：**https://claudeskill.me**

目前覆盖 104 篇 Skill 中文解析，包括：
- superpowers 套件（brainstorming / debugging / testing / dogfooding 等）
- oh-my-claudecode（autopilot / ralph / ultrawork / deep-interview / ccg 等）
- ecc（continuous-learning / tdd-workflow / iterative-retrieval / security-review 等）
- gstack（spec / autoplan / qa / investigate 等）

每篇文章固定结构：一句话简介 / 解决什么问题 / 安装方法 / 核心机制（含 mermaid 流程图）/ 实战 demo / 搭配建议 / 常见坑 / 适合人群。

技术栈：Astro 5 + Pagefind 全文检索 + Mermaid + Cloudflare Workers，全静态站，搜索完全离线，0 后端。

**坦白**：文章由 Claude Opus 4.7 辅助生成，每篇都有 self-check 校验链接、命令、引用源对得上才发布。原始 SKILL.md 都标了 source，方便对照英文版。

**为什么做**：
1. 自己学的过程中本来就在翻译，索性产出来给同样需求的人
2. Claude Code Skills 这个范式（plugin-managed、prompt-as-code）国内还没出现系统化的中文资料
3. 想看看 AI 内容站点这条路在工具教程领域能跑多远

欢迎反馈翻译错漏 / 选题建议 / 你想看哪个 Skill 的解析。GitHub 在 https://github.com/fanshanhong/claude-skills-cn，issue 直接提。
```
