## 正文

```
分享一个宝藏站点，给用 Claude Code 的朋友们

Claude Code 有个叫 Skill（技能）的东西，装上之后 AI 写代码的能力会大幅提升——比如自动 debug、自动写测试、自动做代码审查、甚至自动做 UI 设计。

但问题是：这些 Skill 全是英文，而且不是普通英文，是"给 AI 看的提示词代码"，读起来像天书。

我花了两周，把市面上主流的 104 个 Claude Code Skill 全部做了中文解析，整理成了一个站点：

claudeskill.me

每篇文章都有：
- 一句话说清楚这个 Skill 干嘛
- 什么时候该用 / 不该用
- 安装命令（复制就能装）
- 核心机制流程图（不是干巴巴的文字，是图！）
- 真实使用场景 demo
- 踩坑指南

覆盖的 Skill 套件包括：
superpowers（超能力合集）
oh-my-claudecode（自动驾驶套件）
ecc（持续学习工具）
gstack（工程化套件）
……还有很多单体 Skill

全站免费，不需要注册，搜索也是离线的，秒出结果。

坦白说：这些文章是 AI 辅助生成的（用的 Claude Opus），但每篇都做了人工校验——链接、命令、流程图都核对过源文件。

如果你在用 Claude Code 但还没试过 Skill，强烈建议先看看 superpowers 和 omc 这两个套件的解析，装上之后效率提升很明显。

有问题可以留言，看到就回

#ClaudeCode #AI编程 #Claude技能 #程序员工具 #AI工具推荐 #独立开发 #效率工具 #Claude #Anthropic #AI写代码
```
